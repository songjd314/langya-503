# 一、课题目标与作品定位

## 1.1 命题拆解

本次命题为「琅琊榜世界观连续短剧创作」，评审维度为两项：

| 评审维度 | 具体抓手 | 本作品的应对策略 |
|---|---|---|
| **内容质量** | 琅琊榜关联性、叙事连贯性、画面质感、植入融合度 | 剧情生长在原作主线上；三集构成完整的"起承转合"闭环；商品是推动剧情的**麦高芬**而非贴片 |
| **单位时长成本** | 同等成片质量下，每分钟算力成本越优得分越高 | 全程程序化生产 + 零废弃生成，官方账单**抽卡倍数 1.0 / 积分利用率 100%** |

**关键约束（命题原文）**：使用 Canvas 创作 3 集剧情互相关联的短剧，单集 2–3 分钟；可做世界观衍生原创故事，不强制复刻原版剧情，只需与琅琊榜设定有关联。

## 1.2 作品定位

- **剧名**：《琅琊榜·外传：一盏503》
- **体量**：3 集，单集 2:07–2:33，全片 6 分 56 秒
- **题材定位**：古装权谋 + 商战谍战，真人古装（live_ancient）影视质感
- **时间坐标**：原作主线中「苏哲初入金陵」这一时间点的原创外传
- **创作原则**：**不做原剧复刻，做原剧的一个"如果"** —— 如果赤焰案的兵符信物，当年被藏进了一饼茶里

## 1.3 植入主体

**吉普号 503 普洱茶**（实体商品）。

选择它的理由不是"能植入"，而是它本身就长在琅琊榜的世界观里：

1. **产地即人物故乡** —— 霓凰郡主执掌云南穆府，普洱正是云南产物。穆府贡茶进金陵，天经地义，谁也挑不出错。
2. **形态即掩护** —— 茶饼紧压、棉纸包裹、火漆封印，藏得住东西，也经得起三千里颠簸。
3. **气质即人设** —— 品牌理念「理性普洱」，与苏哲「理性、克制、算无遗策」的谋士形象互为镜像。

## 1.4 核心创意：商品即麦高芬

本剧的设计原点只有一句话：**把商品抽掉，剧情不成立。**

全剧的三段冲突全部架在这饼茶上：

| 集 | 冲突 | 茶在其中的作用 |
|---|---|---|
| 第一集 | 谢氏商行盯上贡茶，黎纲立誓护茶 | 茶是**被争夺的目标**，运输线构成全集的叙事动力 |
| 第二集 | 茶饼撬开，兵符现世 | 茶是**藏秘密的容器**，揭底动作本身发生在烹茶过程中 |
| 第三集 | 同一批茶分送太子、誉王两府 | 茶是**布局的棋子**，借力打力的道具 |

若把茶换成任意其他商品，上述三段冲突会立刻失去物理合理性（藏不进兵符）、失去动机链条（无人会为它劫道）、失去策略价值（无法一式两份分送敌对双方）。

## 1.5 与原作的关联点

| 关联类型 | 具体内容 |
|---|---|
| **世界观承袭** | 大梁、金陵、赤焰案、梅岭、十二年之期 |
| **人物承袭** | 苏哲（梅长苏）、霓凰郡主、飞流、蒙挚、黎纲、太子、誉王 |
| **势力承袭** | 悬镜司阴影下的谢氏、夺嫡格局 |
| **原创设定** | 「兵符藏于茶」——本剧唯一的虚构支点，也是全部剧情的引擎 |
