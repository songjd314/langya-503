# 四、分镜与视听设计

## 4.1 分镜总览

| 集 | 场景数 | 镜头数 | 成片时长 |
|---|---|---|---|
| 第一集《南茶北渡》 | 10 | 28 | 2:33 |
| 第二集《茶中藏锋》 | 5 | 19 | 2:07 |
| 第三集《一盏归心》 | 10 | 19 | 2:17 |
| **合计** | **25** | **66** | **6:56** |

- 镜头平均时长 **6.3 秒**（区间 5–10 秒）
- 单个视频片段上限 15 秒，本剧按场景切分共 **36 个片段**，单次成片

## 4.2 运镜设计

| 运镜类型 | 镜头数 | 使用意图 |
|---|---|---|
| `slow_push_in` 缓推 | 32 | 主力运镜。用于情绪推进与信息揭示（如茶饼撬开、兵符现世） |
| `static` 固定 | 20 | 用于对话与对峙，保证画面稳定、人物清晰 |
| `slow_pull_out` 缓拉 | 5 | 用于场景收尾与章末留白（如江边渡口远景） |
| `crane_up` 升起 | 3 | 用于开场与转场（如茶山云海开场） |
| `pan_right` 右摇 | 3 | 用于街市横移、队伍行进 |
| `handheld` 手持 | 1 | 用于夜斗段落，制造紧张感 |
| `push_in` 推进 | 1 | 强调式推进 |
| `tilt_down` 下摇 | 1 | 用于城楼俯视 |

**设计原则**：以**缓推 + 固定**为主（52/66），刻意压低运动幅度。原因有二：

1. **降低生成风险** —— 大幅运动容易引发人物形变，缓运动显著提升成片可用率
2. **贴合题材气质** —— 古装权谋的叙事节奏本就偏静，运镜服务于"静水流深"

紧张感只在两处刻意释放：夜斗（handheld）与双府对切（对切剪辑）。

## 4.3 画面质感

- **风格**：真人古装（live_ancient），电影级实拍感，非二次元、非水墨写意
- **画幅**：16:9
- **分辨率**：720p（1280×720）
- **色调走向**：

| 段落 | 色调 | 光源 |
|---|---|---|
| 滇南茶山 | 冷青 + 晨雾白 | 晨光 |
| 金陵城门 / 街市 | 暖土黄 + 灰 | 日间自然光 |
| 苏宅夜（茶室） | 暖橙烛光 + 深褐暗部 | 炭炉 / 烛火 |
| 庭院夜斗 | 冷月蓝 + 灯笼暖点 | 月光 / 灯笼 |
| 江边渡口（晨） | 银灰 + 淡金 | 晨雾逆光 |

## 4.4 商品镜头的视觉处理

吉普号 503 在片中共出现 13 个镜头，贯穿三集。视觉处理上遵循三条：

1. **特写给足**：茶饼的棉纸、火漆、太极双鱼标志，用近景与微距呈现，确保品牌资产清晰可辨
2. **不摆拍**：商品始终处于**动作之中**——被装车、被搬运、被撬开、被分装、被递出，没有一帧是静止陈列的展示位
3. **光效优先**：所有商品镜头均安排暖光（晨光 / 烛火），使茶汤与茶饼呈现温润质感，与剧集的权谋冷调形成对比

## 4.5 后期处理（详见 `02-process.md`）

| 项目 | 数量 | 处理方式 |
|---|---|---|
| 资产参考图泄露清除 | 28 处 | 静帧缓推替换 + 淡入淡出，音轨保留 |
| 人物 / 地点首次出场标注 | 13 处 | 3.5 秒左下角介绍字条（半透明深底 + 金色竖条 + 宋体） |
| 硬字幕烧录 | 28 条 | PingFang SC 19px，描边 + 阴影，距底 42px |

### 介绍字条设计

```
┌─────────────────────────────┐
▌ 苏哲 · 江左梅郎              │   ← 宋体 78px，米白
▌ 江左盟宗主 · 天下第一谋士     │   ← 苹方 36px，浅金
└─────────────────────────────┘
  位置：左下 · 距底 118px · 3.5 秒 · 淡入 0.35s / 淡出 0.4s
```

字条出现时机与剧情精确对位。例如第一集旁白响起「茶进金陵那天，江左梅郎，也进了城」时，画面叠的正是「金陵城门 · 大梁帝都」；第二集霓凰第一次出现时叠「霓凰郡主 · 云南穆府统帅」。

## 4.6 声音设计

- **音轨**：Kling V3 同步生成（AAC 立体声 44.1kHz），含旁白、对白与环境音
- **后期处理**：音频全程 `copy` 直拷，不做重编码，保证零音质损失
- **音画关系**：清除模型卡时只替换画面、不动音频，因此旁白与对白的连续性完全不受影响

> **已知限制**：AI 生成音轨存在部分口型不同步现象，属生成模型的固有特性。本轮选择保留原始音轨以保障叙事连贯，未做逐段重新生成（逐段重生约 800–1500 积分/段，且同样无法根治）。

## 4.7 三集节奏曲线

```
第一集  开场缓 → 中段行程蒙太奇（快） → 入城后转为对峙（静） → 悬念收尾
第二集  全程夜戏（静） → 夜斗陡起（动） → 相认未遂（静，情绪高点）
第三集  双府对切（快，信息密集） → 渡口对话（缓） → 落子收束（留白）
```

三集共用一条节奏原则：**信息密度高的段落用快切，情感段落用长镜头留白。**
