# 三、故事与分集设计

## 3.1 世界观前提（原创设定）

原剧设定：十二年前，大梁赤焰军在梅岭遭陷害，七万忠魂埋骨雪原。少帅林殊侥幸生还，削骨换面，化名**梅长苏**，以谋士「苏哲」的身份重回金陵，要把当年真相翻出来。

本剧是这条主线上的一段原创外传，时间点在苏哲入金陵之初。改动只有一个设定：

> **赤焰案的兵符信物，当年被藏进了一饼茶里。**

一饼云南穆府进贡的吉普号 503 普洱。

**为什么藏得进去？** 茶饼紧压、棉纸包裹、火漆封印，藏得住东西，也经得起三千里颠簸。
**为什么没人查？** 全金陵的眼睛都盯着夺嫡，没人会去查一饼茶。
**为什么是普洱？** 霓凰郡主执掌云南穆府，普洱正是云南产物——穆府的贡茶进金陵，天经地义。

## 3.2 人物表

| 人物 | 身份 | 在本剧中的作用 |
|---|---|---|
| **苏哲（梅长苏）** | 江左盟宗主，「江左梅郎」 | 布局者。借茶入金陵，把棋局摆开 |
| **霓凰郡主** | 云南穆府统帅 | 送茶人。隐约察觉面熟，却不敢相认 |
| **飞流** | 苏哲贴身护卫 | 武力担当，夜斗黑衣人 |
| **蒙挚** | 大梁禁军大统领 | 赤焰旧人，苏哲在城内唯一的安全线 |
| **黎纲** | 江左盟舵主 | 押茶队领队，「茶在，人在」 |
| **谢氏商行头目** | 金陵商号主事 | 反方眼线，奉命劫茶 |
| **太子 / 誉王** | 夺嫡双方 | 被苏哲当"锤子"用的两方诸侯 |

## 3.3 三集结构

```
第一集《南茶北渡》  =  起：茶进金陵，各方盯上       （运茶）
第二集《茶中藏锋》  =  承：茶饼撬开，兵符现世       （揭底）
第三集《一盏归心》  =  转合：一茶二送，借力打力     （布局）
```

三集是**同一个动作的三个阶段**，而非三段并列的小故事。任何一集单独抽出来都不成立——这正是"剧情互相关联"的实质保障。

## 第一集《南茶北渡》（2:33）

**一句话**：三十斤贡茶三千里入京，谢氏盯上了它，而他们要的从来不是茶。

| 场景 | 场名 | 内容 |
|---|---|---|
| 1-1 | 外 · 滇南茶山云海 · 晨 | 云雾漫过茶山，采茶人隐现 |
| 1-2 | 外 · 茶山马帮驿道 · 晨 | 马帮装茶出发 |
| 1-3 | 外 · 山水蒙太奇 · 日 | 三千里行程压缩呈现 |
| 1-4 | 外 · 金陵城门 · 日 | 茶车与苏哲的马车同时入城 |
| 1-5 | 外 · 金陵城楼 · 日 | 蒙挚在城楼俯视，低语 |
| 1-6 | 内 · 马车车厢 · 日 | 苏哲品茶，道出三山拼配 |
| 1-7 | 外 · 金陵街市 · 日 | 谢氏商行盯梢 |
| 1-8 | 外 · 金陵街市 · 日 | 黎纲立誓护茶 |
| 1-9 | 外 · 金陵街市 · 日 | 暗流对峙（无对白） |
| 1-10 | 内 · 马车车厢 · 日 | 悬念收尾 |

**关键台词**

> 旁白：「大梁承平十二年。云南穆府的茶，要进金陵了。」
>
> 马夫：「穆府亲点，茶王五十又三。三十斤，一两都不能少。走官道。」
>
> 旁白：「茶进金陵那天，江左梅郎，也进了城。」
>
> 蒙挚：「（低声自语）他终于还是来了。」
>
> 苏哲：「易武的柔，勐海的厚，临沧的甜。三山拼配……穆府的诚意，十足。」
>
> 探子：「谢氏，要这批茶。」
>
> 黎纲：「茶在，人在。」
>
> 旁白：「他们要的，从来不是茶。」

**植入设计**：「茶王五十又三」即 503；「三山拼配（易武 / 勐海 / 临沧）」为 503 的真实工艺，由主角之口在品鉴场景中说出，不是旁白念稿。

## 第二集《茶中藏锋》（2:07）

**一句话**：茶饼里藏了十二年的兵符现世，而霓凰凝视眼前人，终究没能认出。

| 场景 | 场名 | 内容 |
|---|---|---|
| 2-1 | 内 · 苏宅书房 · 夜 | 苏哲独对茶饼 |
| 2-2 | 内 · 苏宅茶室 · 夜 | 烹茶，米汤感与木质香 |
| 2-3 | 内 · 苏宅茶室 · 夜 | 蒙挚点破来意 |
| 2-4 | 外 · 苏宅院门 · 夜 | 谢氏派人上门索茶 |
| 2-5 | 外 · 苏宅庭院 · 夜 | 飞流出手、霓凰解围、相认未遂 |

**关键台词**

> 旁白：「赤焰的旧物，在茶里，藏了十二年。」
>
> 苏哲：「水温要够，火候要稳。急不得。」
>
> 苏哲：「米汤感，木质香，无堆味。好茶。云南十二年的时光，都在这一盏里。」
>
> 蒙挚：「你把它带进金陵，是想翻案。」
>
> 苏哲：「不是翻案。是让该看见的人，看见。」
>
> 谢氏：「交出来。留你全尸。」
>
> 霓凰：「谁敢在金陵，动云南穆府的茶。」
>
> 霓凰：「（极低声）这茶……是我给一个人备下的。他若还在，也该是先生这个年纪了。」
>
> 苏哲：「郡主，认错人了。」
>
> 旁白：「她没认出他。他也不敢让她认出。」

**植入设计**：「米汤感、木质香、无堆味」是 503 的真实品鉴描述，被编织进烹茶动作（水温、火候）之中；「云南十二年的时光」把商品陈化年份与剧情时间跨度（赤焰案十二年）叠成同一句话——**产品属性与叙事时间轴同构**。

## 第三集《一盏归心》（2:17）

**一句话**：同一批茶分送两府，让太子和誉王抢着去敲谢玉的门。

| 场景 | 场名 | 内容 |
|---|---|---|
| 3-1 | 外 · 金陵夜色 · 夜 | 棋局摆好 |
| 3-2 | 内 · 太子府正厅 · 夜 | 太子收礼 |
| 3-3 | 内 · 誉王府书房 · 夜 | 誉王收礼 |
| 3-4 | 内 · 双府对切 · 夜 | 两家各得一半，各以为得全部 |
| 3-5 | 内 · 苏宅棋室 · 夜 | 苏哲道出真实目的 |
| 3-6 | 外 · 谢氏商行门前 · 夜 | 谢氏被两府夹击 |
| 3-7 | 内 · 宫城暗廊 · 夜 | 暗流延伸（无对白） |
| 3-8 | 外 · 江边渡口 · 晨 | 霓凰提及梅岭埋茶 |
| 3-9 | 外 · 江边渡口 · 晨 | 苏哲接出当年约定 |
| 3-10 | 外→内 · 江面远景→苏宅案头 · 晨 | 落子收尾 |

**关键台词**

> 旁白：「棋局，已经摆好了。」
>
> 太子：「（冷笑）好一份茶礼。」
>
> 誉王：「他也送了我一份。同一批茶……分了两家？」
>
> 旁白：「同一批茶，卖了两家。」
>
> 苏哲：「让太子和誉王，替我把谢玉的门，敲开。」
>
> 旁白：「劫茶的，成了自己的罪证。」
>
> 霓凰：「这茶……当年我埋了一坛在梅岭。你怎么会知道？」
>
> 苏哲：「因为埋茶的人说过——茶会替她，一直等。」
>
> 旁白：「第一子落定。这盘棋，才刚刚开始。」

**植入设计**：「一式两份分送敌对双方」这一计谋，只有在茶这种**可分割、可复制、有独立价值**的商品上才成立——若换成一件孤品（如一把剑、一幅画），此计在物理上无法成立。这是植入深度的最高体现：**商品属性直接决定了策略设计**。

**情感落点**：全剧最柔软的一句在结尾。霓凰说她在梅岭埋过一坛茶，苏哲答出只有当年那个人才知道的话——他知道，是因为他就是那个人。但两人都没有说破。茶的意象在此完成最后一重转化：**从证物 → 棋子 → 信物**。

## 3.4 植入融合度自检

| 检查项 | 结果 |
|---|---|
| 商品是否可被移除而不破坏剧情？ | **否** —— 移除后三段冲突全部失去支点 |
| 产品卖点是否由角色自然说出？ | **是** —— 三山拼配、米汤感、木质香、无堆味、十二年陈化，全部嵌在品鉴与烹茶动作中 |
| 商品是否出现在关键道具位置？ | **是** —— 撬茶、藏兵符、分送三处均为剧情转折点 |
| 商品是否承担叙事功能？ | **是** —— 运输线（集1）、秘密容器（集2）、策略棋子（集3）、情感信物（集3尾声） |
